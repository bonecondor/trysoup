Checkpoint is an interactive SMS art project by Secret Soup Company. For a plain-language description of the program and opt-in flow, visit the Checkpoint program page.

Program name

Checkpoint, operated by Secret Soup Company.

Program description

Checkpoint is an interactive ambient art project. Participants opt in in person by physically tapping an NFC sticker on a real-world object or installation. The sticker or attached card identifies the program as Checkpoint by Secret Soup Company and displays the SMS disclosure before any text is sent. Tapping the sticker opens a pre-written SMS in the participant's native messaging app, and the participant must manually press Send to begin. Sending that first text constitutes consent to receive replies. Once opted in, you may receive conversational text replies and occasional continuation or check-in messages from the project.

Message frequency

Frequency varies. Messages are sent conversationally in response to your texts, plus occasional project-wide check-ins. Typical participants receive a small number of messages per month.
